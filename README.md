# KOVAX · King of the Pitch (Season 01)

Registration website for a PlayStation football tournament in Addis Ababa.

## Tournament info
- 32 players
- 800 ETB entry fee
- 10,000 ETB prize

## Features
- Mobile-friendly design
- Registration form with checks (name, Ethiopian phone number, gamer tag)
- Stops duplicate phone numbers
- Closes at 32 players

## Tech
HTML, CSS, JavaScript (no frameworks). Registrations are saved in the browser with localStorage for now.
